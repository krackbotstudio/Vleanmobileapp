# Vleanmobileapp

Vclean customer laundry mobile app connected to the Bubbler platform (`com.vcleanlaundry`).

## Current build

- Customer mobile app for Vclean brand.
- Connected to Bubbler API (`https://apibubbler.krackbot.com/api`).
- Phone OTP sign-in, account management, address management, and order history.
- Live branch catalogue and real-time service pricing.
- Home screen with interactive 3D service orb and pickup scheduling.

## Local development

```powershell
.\flutter-local.ps1 test
.\flutter-local.ps1 analyze
.\run-local-preview.ps1
```
